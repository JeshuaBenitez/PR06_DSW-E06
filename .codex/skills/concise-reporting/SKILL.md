# Informes concisos de PR06

Comunica primero el resultado principal y usa sólo el detalle necesario para que el trabajo pueda revisarse.

Incluye, cuando corresponda:

1. Resumen de los cambios o hallazgos.
2. Archivos creados, modificados o eliminados.
3. Pruebas o verificaciones ejecutadas y su resultado.
4. Fallos, limitaciones, riesgos y pruebas no ejecutadas.
5. Pendientes que requieran otra tarea o decisión.

## Reglas de claridad

- No ocultes errores ni pruebas omitidas para ahorrar tokens.
- Distingue `VERIFICADO`, `NO_VERIFICADO` y `PENDIENTE` conforme a `AGENTS.md`.
- Evita saludos, introducciones repetitivas y explicaciones que no cambien una decisión.
- No reproduzcas archivos completos salvo que el usuario lo solicite; enlaza archivos o muestra fragmentos relevantes.
- Incluye una explicación técnica breve cuando sea necesaria para entender una decisión, un error o una limitación.
- No presentes planes, documentación histórica ni artefactos existentes como evidencia de una ejecución actual.
